# Leakage Research

Repositório dedicado ao estudo e modelagem de Machine Learning para detecção de vazamentos utilizando dados do dataset LeakDB, com cenários gerados em EPANET, e análises exploratórias em Python.

## Estrutura do Projeto
- `data/`: Contém os dados utilizados no desenvolvimento.
- `dev/`: Contém os notebooks Jupyter com as análises e testes iniciais.
